# Iluminación LED en red de 74 VCC — Locomotoras EMD N.º 49 y N.º 50

Memoria de cálculo y esquemas gráficos para reemplazar las ampolletas incandescentes
de 74 V (numeradores, luces de clase y culata, cabina, instrumentos y estribos) por
tiras LED de 24 VCC alimentadas mediante Módulos Conversores de Iluminación (MCI,
DC/DC ferroviario 40–160 VCC → 24 VCC, 30 W).
